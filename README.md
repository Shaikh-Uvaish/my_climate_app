🌤️ Climate App

A Flutter-based climate application designed to provide users with weather-related information through a clean and intuitive mobile interface.

📌 Overview

Climate App is a mobile application project built using Flutter and Dart. The project focuses on presenting climate and weather information in an accessible format while exploring Flutter application development and backend integration.

✨ Features

- Weather-focused mobile application.
- Custom UI with reusable visual assets.
- Custom typography and styling.
- Dedicated backend directory for backend-related development.
- Cross-platform Flutter project structure.

🛠️ Tech Stack

Technology| Purpose
Flutter| Cross-platform UI development
Dart| Application logic
Backend| Server-side functionality
Git & GitHub| Version control

🚀 Getting Started

Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

Installation

1. Clone the repository

git clone https://github.com/Shaikh-Uvaish/my_climate_app.git

2. Navigate to the project directory

cd my_climate_app

3. Install dependencies

flutter pub get

4. Run the application

flutter run
